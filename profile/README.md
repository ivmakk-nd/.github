# Nomad Drive mods by ivmakk

Open-source mods for *Nomad Drive*. Each mod is free on Nexus Mods, and its source code is here.

## Mods

| Mod | What it does | Version | Download |
|---|---|---|---|
| [Item Highlight](https://github.com/ivmakk-nd/nd-item-highlight) | Highlight every item you can pick up around you. | 1.1.0 | [Nexus Mods](https://www.nexusmods.com/nomaddrive/mods/26) |
| [More Hotbar Slots](https://github.com/ivmakk-nd/nd-more-hotbar-slots) | Carry up to 10 items in your hotbar. | 1.0.0 | [GitHub](https://github.com/ivmakk-nd/nd-more-hotbar-slots/releases) |
| [Restoration Tools Tweaks](https://github.com/ivmakk-nd/nd-restoration-tools-tweaks) | Resize the brush of the restoration tools, see its size, and drain only for surface you change. | 1.0.1 | [Nexus Mods](https://www.nexusmods.com/nomaddrive/mods/25) |

## Install

Each mod needs the [Nomad Drive BepInEx Pack](https://www.nexusmods.com/nomaddrive/mods/7). Install it first, then extract the mod's zip into the game folder. The README of each mod gives the full steps.

## Bugs and ideas

Open an issue in the repo of the mod, or post on its mod page. For a bug, add your game version and the log file: `BepInEx\LogOutput.log` in the game folder.
